点击按钮 → 弹出「在 Loon 中打开？」→ 确认即可

⬇️ 导入进阶配置（raw） https://www.nsloon.com/openloon/import?url=https://raw.githubusercontent.com/dranklim/loon/main/config/Loon_Advanced.conf ⬇️ 导入进阶配置（jsdelivr · 国内直连） https://www.nsloon.com/openloon/import?url=https://gcore.jsdelivr.net/gh/dranklim/loon@main/config/Loon_Advanced.conf ⬇️ 导入懂球帝去广告插件 https://www.nsloon.com/openloon/import?plugin=https://raw.githubusercontent.com/dranklim/loon/main/plugins/Dongqiudi_remove_ads.plugin

· 点击无反应时，长按复制下方小字链接，在 Loon → 配置 → 从 URL 下载中粘贴
· 导入配置后需在 Loon 内重新生成 MitM 证书并信任
· 节点订阅需自行添加（配置不含订阅）
